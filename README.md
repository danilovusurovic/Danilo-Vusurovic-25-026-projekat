# Cetvrta Nedelja

Jednostavna Java igra – zadatak sa klasama `Player`, `Enemy` i `Game`.

- `Player` – ime (automatski formatirano), pozicija, dimenzije, health (0–100)
- `Enemy` – tip, pozicija, dimenzije, damage (0–100)
- `Game` – detekcija sudara, smanjenje health-a, pretraga po tipu, event log

## Pokretanje

```bash
javac Game.java
java Game
```
